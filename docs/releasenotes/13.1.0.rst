API changes
===========

Checking PNG text keys
^^^^^^^^^^^^^^^^^^^^^^

:py:meth:`~PIL.PngImagePlugin.PngInfo.add_text` and
:py:meth:`~PIL.PngImagePlugin.PngInfo.add_itxt` now raise a :py:exc:`ValueError` if
the key is empty, longer than 79 characters or contains a null character.

PNG text keys must be 1 to 79 characters long, and libpng ignores zTXt and iTXt
chunks with other keys. A null character ended the key early: the rest of the key was
read as part of the value, the chunk was ignored, or the image could not be opened.

Other changes
=============

Resizing I;16B and I;16N images
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

On little-endian systems, :py:meth:`~PIL.Image.Image.resize` read and wrote
I;16B and I;16N pixel values in the wrong byte order when using a resampling
filter other than ``Resampling.NEAREST``. This has been fixed.

Blurring I;16 images
^^^^^^^^^^^^^^^^^^^^

:py:class:`~PIL.ImageFilter.GaussianBlur` and :py:class:`~PIL.ImageFilter.BoxBlur`
now support I;16, I;16L, I;16B and I;16N images.
