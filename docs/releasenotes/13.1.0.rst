Other changes
=============

Blurring I;16 images
^^^^^^^^^^^^^^^^^^^^

:py:class:`~PIL.ImageFilter.GaussianBlur` and :py:class:`~PIL.ImageFilter.BoxBlur`
now support I;16, I;16L, I;16B and I;16N images.

ImagePath.Path coordinate handling
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

:py:class:`~PIL.ImagePath.Path` item assignment now accepts two-element lists.
Errors during coordinate conversion are raised as normal Python exceptions, and
integer coordinates are converted without losing precision through an intermediate
C ``float``.
