Other changes
=============

PCX and ZIP decoder row sizes
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

When using :py:meth:`~PIL.Image.Image.frombytes()` with the ``pcx`` decoder and a
caller-supplied stride, packed 2- and 4-bit rows padded to a byte boundary were
collapsed incorrectly, and the row-size arithmetic could overflow for very wide
images. The ZIP decoder no longer accepts planar raw modes when interlacing is
requested, since it cannot decode them correctly.

Resizing I;16B and I;16N images
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

On little-endian systems, :py:meth:`~PIL.Image.Image.resize` read and wrote
I;16B and I;16N pixel values in the wrong byte order when using a resampling
filter other than ``Resampling.NEAREST``. This has been fixed.

Blurring I;16 images
^^^^^^^^^^^^^^^^^^^^

:py:class:`~PIL.ImageFilter.GaussianBlur` and :py:class:`~PIL.ImageFilter.BoxBlur`
now support I;16, I;16L, I;16B and I;16N images.
